# روح مشوار — Multi-platform starter
هذا مشروع Flutter مبدئي للعميل، قابل للبناء على Android و iOS.

## تشغيله
1. ثبّت Flutter SDK.
2. شغّل `flutter pub get`.
3. Android: `flutter run` أو `flutter build apk --release`.
4. iOS: افتح مجلد ios في Xcode، أضف إعدادات Apple Developer، ثم Archive/Run.

## النسخة الحالية
- واجهة رئيسية RTL.
- إنشاء طلب تجريبي.
- قائمة الطلبات.
- الحساب.
- أساس جاهز لإضافة الخرائط، API، قاعدة البيانات، السائق والإدارة.

ملاحظة: الخرائط والخادم والإشعارات تحتاج مفاتيح وخدمات خارجية قبل إطلاق الإنتاج.
